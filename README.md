# playwood. APP

A local, full-window furniture design workspace built with Vite, React, TypeScript, Three.js, React Three Fiber, and shadcn/ui components backed by Radix. Warm neutral colors, restrained controls, and independent scrolling inspectors keep the assembly in view.

For implementation details, see the [architecture and development documentation](docs/README.md). Coding agents should start with [AGENTS.md](AGENTS.md).

On narrow screens, **Open panel list** and **Open inspector** open keyboard-accessible drawers. Tab and Shift+Tab stay inside the drawer; Escape cancels a nested task first, then closes the drawer and returns focus to its opener. Background controls are inactive until the drawer closes. Desktop sidebars keep ordinary navigation.

Rejected editing commands show an **Action not applied** notice with the reason. It stays visible while you inspect the construction, including inside a narrow drawer, until you dismiss it or a later error replaces it. Successful actions keep brief confirmations.

## Run

Requires Node.js 22.12+ (tested with Node 25).

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. No accounts, API keys, backend, or external fonts are required. Projects autosave in this browser's local storage; export a JSON project or use **Sync** to keep editable files in a local folder.

Choose **Import** beside **Export project** in the header to open a saved `.playwood.json` project without connecting a folder. Import replaces the workspace and supports Undo; export first to keep a separate copy. Invalid files show an error without changing the current build. If you edit while an import is reading, it cancels with a retry message; choosing another file supersedes the earlier request.

If a browser save cannot be opened, a recovery notice appears and autosave pauses. **Download original save** preserves the original file for recovery. **Reset browser save** saves the current workspace after keeping a separate backup of the unreadable original on this device. Export your current work if you want to keep editing without resetting.

When another tab changes the browser save, autosave pauses in this tab. **Download this workspace** keeps your version as a file; **Open browser save** switches to the newer save after keeping a local backup, with Undo available. Pending edits survive a reload in the same tab. Download conflicting work before closing its tab. Projects support up to 200 panels and 400 connection records; edits exceeding these limits leave the current project intact.

## Sync a local folder

Choose **Sync** next to **New project**, then **Choose folder** and allow read/write access. The folder's project and assembly JSON files appear in the dialog. Folder access requires a browser that supports the File System Access directory picker, such as desktop Chrome or Edge. Browsers without it retain browser autosave and the existing import/download controls.

Connected folder projects also appear in **Library → Full builds → Synced folder projects**, labeled **Folder sync** with their filenames and folder name. Search finds them by project name, filename, or folder name. Cards load previews asynchronously as they come into view, with a loading indicator while the file is read. Built-in examples remain available while folder previews load. Previews use the same simplified panel drawing as the example library; projects without panels show “No panels to preview”. Opening one uses the Sync dialog’s existing save/open confirmation. Use **Sync → Resync** to refresh external changes.

The **Sync** button shows a green check badge while a folder is connected. An amber **!** means the folder needs attention or reconnection; open Sync for details. Both badges remain visible in the compact header.

- **Save project** saves the current workspace into the folder, or updates its opened file. **Duplicate project** saves a separate copy; each listed project also has a Duplicate action. New copies use unique filenames without replacing existing files.
- **Open** loads a listed project. If the current workspace has unsaved folder changes, choose **Save and open**, **Open without saving**, or **Cancel**. Opening remains undoable during the session.
- Enable **Autosave to folder** after opening or saving a project to write accepted edits to that file. Enable it again when you open a different project. The browser recovery save remains automatic even when folder autosave is off. Starting, importing, or replacing a project, or undoing across a project change, releases the file association so another project cannot be autosaved over it.
- The folder is remembered in this browser. After reloading, choose **Sync → Resync** to reconnect and refresh the list; the browser may ask for permission again. Open a file or save the recovered workspace explicitly before enabling folder autosave again. **Change folder** chooses another location; **Forget folder** removes remembered access without deleting files.
- Under Assemblies, use **Import assembly into folder** to copy a validated assembly file into the folder. Choose an existing project instance under **Assembly to export**, then **Export assembly to folder**. **Insert** on a listed assembly adds it through the normal assembly insertion or attachment-preview workflow.

Sync reads JSON files directly inside the chosen folder; it does not scan subfolders or watch for external edits. **Resync** refreshes the listing without replacing the workspace. If an opened file changes or disappears outside the app, saving stops and folder autosave pauses. Preserve your edits with **Duplicate project**, then reopen the disk version if needed. Project and assembly files use their existing formats and the 2 MB import limit; no cloud account or server is involved.

Below the **Studio / Realistic preview** switch, the collapsible **Rescale** section starts collapsed, shows its slider count in a badge, and contains up to four sliders exposing the most-used changeable panel dimensions (at least two uses each). Dimensions that cannot move by one configured step in either direction are omitted. Drag to preview matching cuts together; release applies one undoable edit, and Escape cancels. Sliders use the **Only nice values** step when enabled, otherwise 1 mm. Each slider normally spans half to twice its current dimension, narrowed by solver checks and aligned to the configured step. Its range and measurement group stay fixed throughout a drag, even when values cross; release recalculates the range for the next edit. Incompatible sizes keep the last valid preview and show a message.

The preview’s **Rescale creation** button shows the configured step value in a green badge while **Only nice values** is enabled.

The preview’s **All constraints** button shows a badge counting saved rules (including paused rules) plus enabled Build space. Open it to see measurement lines with small type markers: blue cut dimensions, green floor/level references, purple gaps/opening ratios, and ochre fixed positions/setbacks. End ticks mark cuts, inward arrows mark clear gaps, ground marks locate floor heights, and anchors identify fixed positions. Paused rules use gray dashed lines. Hover a line or marker, or focus a marker with the keyboard, to reveal the rule’s measurements and panel names. Related measurements highlight together; opening rules show both gaps and their ratio in one tooltip. Inspector row hover/focus also shows measurements, and editing isolates the draft. Closing the inspector hides the rule overview. Guides appear in Studio, outside exploded view.

Click an amber overlap icon in the panel list to open **Fix panel overlaps**. Review the proposed size and position changes for every affected panel, then choose **Apply automatic fix**. Cancel or Escape leaves the construction unchanged; Undo restores an accepted repair. Automatic repair tries joint-preserving moves and edge trims. If none fit the existing rules, the dialog explains that manual editing is needed.

## Design workflow

While dragging a panel resize arrow, the inspector’s panel values update live with the preview. Connected edge drags resize the connected structure while keeping the opposite edge fixed. Equal coplanar halves at a T/cross joint keep their split centered automatically—for example, resizing the H-table tabletop depth grows both leg halves equally and keeps the spine at 50/50. Moving the divider off center or resizing a half directly breaks this inferred relationship; no saved constraint is added. A narrow panel centered along a shared joint also follows that joint’s midpoint: resizing either large Island display platform keeps the upper shelf centered while retaining its depth. Moving the upper tier off center breaks that inference. Hold Shift to resize only the selected panel, keeping other panels and hardware fixed. A limit keeps the reachable preview and explains the blocker. A successful connected drag applies one undoable edit. After a limit, **Review resize alternatives** can offer a deliberate change of behavior; the drag never silently switches to keeping attached cuts fixed. Cancel or Escape restores the original construction. Larger connected edge previews run in the background; Escape also cancels a pending release.

Select two aligned panels and open **Build tools → Merge panels**, or right-click the preview and choose **Build → Merge panels**, to replace them with one continuous rectangle across the gap. Matching solid rectangular panels must share orientation, thickness, material, finish, and the full edge length across the gap. Their outside edges, surrounding panels, and installed hardware stay fixed. The first selected panel keeps its name and identity. Merging supports Undo/Redo, autosave, and project export. Custom outlines, rounded corners, perforations, inserts, linked assemblies, saved rules on either panel, and joints crossing the gap must be handled first; incompatible joints or obstacles reject the merge without changing the build.

The inspector’s **Scene location** box starts collapsed, with ground clearance always visible at the right of its heading; click the heading to expand it. It shows the selection’s X/Y/Z From, To, and Center coordinates, signed ground clearance, and single-item rotation in degrees. Y is up and ground is Y = 0. Multiple selections show combined bounds. Panel measurements use rectangular stock bounds without accessories; connector measurements use CAD envelopes including slide offsets; objects use source-box bounds (including Boolean cutters). Values are read-only and use millimeters.


- Open **Assembly → Objects → Add a box** to sketch with translucent blue volumes and outlines; selected objects appear in magenta. Enter **Box width/height/depth**, center coordinates, and 90° rotations, then **Apply object changes**. **Cancel** or **Escape** discards the draft. Boxes use outside dimensions in millimeters. They appear in Studio and disappear entirely in Realistic preview and exploded view.
- In Objects mode, click a shape in the preview or its object row to select it; Shift-click selects several shapes. **Union** removes internal surfaces; **Subtract** removes later-selected operands from the first; **Intersect** keeps their common volume. The nested list keeps every source box editable, including cutters. Select a Boolean object to change its operation or move operands earlier in its order. Hidden operands still participate in their parent operation; hiding a top-level object hides its whole preview. Empty and overly complex results show a message.
- In Objects mode, focus the canvas and use arrows to move the selection (10 mm, or the enabled grid spacing; Shift multiplies the step by ten). **X/Y/Z** or **Rotate X/Y/Z 90°** rotate around the source selection's center. Multiple-object center and source-size fields move or scale all selected source boxes together. Duplicate, copy/paste, and removal operate on complete top-level trees. These operations support Undo/Redo, browser saves, and project JSON. Switch to Panels or Connectors to edit furniture through the blue volumes. Hold **Control** and drag a selected object to move it, or drag its resize arrows to scale the selection while keeping the opposite side fixed. Release saves one edit; Escape cancels. **B** selects visible object roots with a rectangle (Shift adds). Grid and geometry snapping apply to movement and resizing; geometry targets are unselected source-box boundaries and visible panel boundaries. Source objects do not enter parts lists, cutting exports, or standalone assembly files.
- Select one or more top-level objects and choose **Convert to panels**. Boxes and Boolean trees whose evaluated result is one solid cuboid or a common-depth profile with 6–12 boundary edges (including L, U, and stepped shapes) are supported; touching unions become a single shell without internal walls, and intersections or trimming subtractions use the result’s actual bounds. Set thickness (16–19 mm), material, finish coverage/color, and connector appearance. Enable **Rectangular panels only** to exclude custom-shaped panels from the generated construction. This option is off by default. For supported L/U/stepped profiles, it splits each closing face into rectangles attached to the surrounding walls with 90° connectors. Neighboring pieces meet at seams without connectors between them. A U face can use two full-height side pieces and a shorter middle piece. Conversion is unavailable if the cuts, wall attachments, or hardware cannot fit. Review the construction (six panels for a cuboid; one rim panel per profile edge plus two closing faces), installed hardware count, and achieved outside dimensions; **Create panels** accepts once, while **Cancel** or Escape changes nothing. Acceptance keeps the source tree hidden and creates independent ordinary furniture. Remove panels to make openings, then continue editing normally; Undo/Redo and project saves retain both source and furniture. Dimensions exclude projecting hardware. Conversion checks existing furniture, hardware, inserts, project limits, and build space without moving existing parts. Concave profiles retain their notches in two fitted custom-outline closing panels. Each rim edge has a corner joint and joints to both closing faces; short edges or cramped hardware can prevent conversion. Cuboids with up to four separate rectangular corner cutouts also convert to a connected shell of rectangular panels, including cutouts that stop at different heights. Narrow pieces or crowded joints can prevent conversion. Three-axis crosses with three to six full-face rectangular arms also convert to a connected shell of rectangular panels, preserving open space between arms. Stepped solids with all filled columns starting at a common plane also convert in any orientation, provided their faces and hardware fit. When connector gaps would leave narrow cuts, the solver can use fitted outline faces and selected corners that meet without hardware; panels retain at least two supporting neighbors, with a last-resort exception for convex rectangular outer end caps, which may attach to one neighbor. The review identifies these end caps. The whole assembly remains connected. Leave Rectangular panels only off to allow fitted faces. Source dimensions stay unchanged; cuts below 40 mm and layouts with insufficient hardware clearance are still rejected. Enclosed cavities, multiple or non-rectangular tunnels, other changing-depth results, profiles above twelve edges, incomplete or three-dimensional compartment grids, partial shared faces, and live regeneration are not supported yet. A box with one rectangular through-opening converts to sixteen rectangular panels: four outer walls, four opening walls, and four pieces around the opening on each closing face. A rectangular opening that stops inside the box converts as a blind recess with fourteen rectangular panels, including an internal back panel connected through the surrounding walls. The opening, recess depth, and outside dimensions are preserved; hardware may project into the opening. Disconnected Boolean results convert as separate closed pieces, provided every piece is supported and has clearance; the review names each piece. Empty and unsupported results explain why conversion is unavailable. Red outlines in a failed conversion preview locate affected source regions, with their names listed below; existing furniture stays visible for context.
- Multiple selected roots remain separate compartments. Separated objects convert together; straight rows and complete rectangular grids of cuboids with matching full faces share centered dividers using 18–19 mm stock, T joints, and interior cross joints. Grids can have unequal row and column sizes and lie on any world plane. The combined outside envelope stays fixed, and the review lists clear interior dimensions after accounting for wall thickness. Metal appearance applies to 90° hardware; T and cross connectors remain colored plastic. Overlapping source bounds require a Boolean operation, even when custom-profile notches might leave room. Conversion rejects partial shared faces, isolated edge/corner contacts, and incomplete or three-dimensional compartment grids. All selected sources are hidden together only when the complete candidate is accepted.
- **Library → Full builds → Cat tower** opens a six-level tower on a 2×2-bay footprint. It uses eighteen 300×300 mm and twenty 635×300 mm panels plus six 50×300 mm central reinforcing walls, all 18 mm thick. The user-optimized export supplies walnut and warm-white painted panels, the custom palette, and individual connector finishes and adjustments. Each tier’s central wall connects to the landings above and below. L-shaped landings leave a 300 mm climbing opening that rotates around the tower; each level has a floored, open corner below the next opening. - Start with a shelf, desk, display, a resource example from the Library, or a blank project. **New project** in the header opens a confirmation before clearing the workspace; choosing a full build from the Library or Templates also asks before replacing it. Use **Export current project** there to keep a separate copy, then **Start new project** or **Replace project**. Large library builds show an **Opening…** notice while loading into the workspace. The browser save is replaced too; Undo can restore the previous project until you reload or close the app.
- Add your own panels with dimensions in millimeters, material, finish color, and thickness. Choose solid, pegboard, or rounded slots; holes are real openings through the mesh.
- Under **Material & finish → Material**, choose **OSB** for layered wood strands or **Nazena recycled textile** for a blue-gray compressed-fiber surface, inspired by the [PlayWood kits](https://www.playwood.it/en/shop-kit/). Both have textured faces and cut edges in Studio and Realistic preview. Use **0% Finish coverage** for the natural texture, or increase it for a tinted or solid finish. Material choices support undo/redo, copies, assemblies, autosave, and project exports.
- Panel finish colors come from the project palette. Use **Add color** to create a named swatch, or **Manage palette** to rename, edit, or remove custom colors. The color picker edits a local draft; **Save color** commits it once, then click its swatch to apply it. Editing a palette color updates its uses throughout the project; removing an in-use color lets you choose a replacement. Palette changes support undo/redo and are saved automatically and included in project exports. Older projects' unlisted panel colors become named swatches on opening. New connector joints default to the most-used color among installed connectors, including individual color changes and ignoring removed pieces. This applies to hole filling, automatic connections and splits, move-and-snap, paste attachments, and the attachment form. You can still choose a different color in the form; projects without installed connectors start with red.
- **Finish coverage**, under **Material & finish**, blends from **0%** natural material grain to **100%** solid finish color. Intermediate values show tinted grain. Matching selections can change together; a **Mixed** coverage field is disabled. Coverage changes support undo/redo, autosave, and project files. Assembly instances have their own coverage override under **Appearance**, separate from panel color.
- Open **Shape & surface** in the panel inspector and choose **Create custom outline** to open the vector editor. Drag points, double-click an edge (or use **Add point**) to insert a vertex, or enter exact X/Y coordinates in millimeters from the top left. Grid snapping, Shift to lock a drag axis, Alt to bypass snapping, arrow-key nudging, zoom/pan, and local undo/redo support precise edits. **Apply outline** saves one project edit; **Cancel** discards the draft. Outlines scale with panel width and height, and corner radius rounds both outward and inward corners. The inspector shows the finished shape; **Reset to rectangle** removes the custom outline. Project files retain the normalized vertices and cutting lists export their millimeter coordinates. General connector placement and overlap checks still use the panel’s rectangular bounds; automatically fitted hole closures track their own outline edges. Automatic rectangular splitting is unavailable for custom outlines.
- Select a solid horizontal rectangular panel and open **TROFAST inserts → Add TROFAST item** to fit an IKEA box or compartment tray through a cutout. Choose from eight plastic, mesh, and tray shapes and their available IKEA Switzerland colors. The rim rests on the panel and the body hangs below. The editor checks footprint, a 20 mm border, the floor, surrounding panels (including hidden ones), other inserts, and connector clearance. Rotate the item, click or drag the panel diagram, use its arrow keys (10 mm; Shift: 1 mm), or enter exact center coordinates measured from the panel’s top-left corner. A live 3D preview remains separate until **Add TROFAST box** or **Save TROFAST changes**; Cancel/Escape discards it. Add multiple items where space permits, and edit or remove them from the same section. Items and openings follow their panel, support undo/redo and autosave, and survive project/assembly exports. Product sizes stay fixed when panels resize. The current catalogue is based on IKEA Switzerland; colors and rim/cutout profiles are visual approximations. **Measure the real item before cutting:** the displayed opening and exported cutout notes are not fabrication templates.
- Select a panel in the model or panel list. **Dimensions** and **Connection** or **Placement** come first in the inspector. Expand **Shape & surface** or **Material & finish** for secondary properties; section expansion is remembered for the session. Header badges identify custom shapes and surfaces, fitted TROFAST items, saved constraints (including disabled rules in the current scope), and assembly appearance overrides, even when collapsed. Open **Build tools** operations only when needed. Change dimensions, position, and orientation in their sections. Width and height edits apply on Enter or when leaving the field; connected panels adjust together to keep their joints aligned. Attached angled trays and stoppers keep their cuts while following a moved shelf unless the edit, joints, or saved rules require a size change. Short branches can retain their depth beside a much deeper panel; modest existing joint setbacks still follow connected edits.
- Select two or more ordinary panels whose sizes differ in exactly one dimension (width, height, or thickness), then right-click the preview and choose **Make sizes equal**. Choose an existing size or enter a custom value while viewing every selected panel’s dimensions and all resulting size/position changes. **Apply equal sizes** preserves joints and saves one undoable edit; Cancel/Escape changes nothing. Invalid fits are blocked. Disassemble linked assembly members first.
- Moving a single interior shelf or divider perpendicular to its face first adjusts adjacent spans while keeping surrounding panels fixed. When that cannot fit, **Review wider movement** may offer moving the nearest feasible compartment boundary or moving the outer boundary while preserving the cuts ahead. Review changed cuts, positions, and outside size, then **Apply movement** as one undo step; **Cancel** or Escape keeps the construction. This applies to keyboard/viewport movement in orthogonal constructions, including rotated frames. Other movement types and resize gestures retain their existing behavior.
- Numeric Width/Height edits can open **Review resize alternatives** when several valid outcomes fit the construction—even if the resize could already succeed. Choose **Keep attached sizes**, an end alignment, or **Keep both margins**; compare the affected cuts, center positions, and outside size. The affected panels are highlighted. End names refer to panel-local cuts before rotation. Saved rules and physical joints stay enforced; new rectangular-bound overlaps are rejected and existing overlap measurements cannot increase. **Cancel** or Escape changes nothing. **Apply resize** saves one undoable edit. Unambiguous edits apply directly. Resize arrows and assembly controls retain their existing behavior.
- Open **Snap** in the preview to independently enable the **global grid (G)** and **geometry alignment (S)**. Set grid spacing and snap tolerance in millimeters; preferences are remembered in this browser. The grid starts at the world origin. Geometry alignment uses world-axis panel boundaries (bounding extents for rotated panels), or other connector centers when moving connectors. **Show grid** controls guide visibility separately. Snapping applies to panel drags, resize arrows, and keyboard movement; with the grid enabled, arrows move one grid spacing and Shift moves ten. Joint and hardware limits still apply, and existing drag-to-attach behavior remains available.
- Right-click a panel selection and open **Add constraints** for one-click rules prefilled from the current geometry. Suggestions appear only when they apply to the selection and are not already saved: **Stick to ground** for panels resting on the floor (or **Keep bottom … above floor** for one raised panel), **Lock width/height** at the current cut, **Keep … equal** or **Match … to** the first selected panel for cuts running the same way, **Keep bottoms/tops level** or **Align … with** the first panel for parallel panels, the measured gap between two panels, **Distribute equally** (or **Keep spacing equal**) for three or more parallel panels, and **Pin current position** for one panel. Match, Align, and Distribute adjust panels before saving the rule; the others keep geometry unchanged. Each click is one Undo step. Linked assembly members get no suggestions.
- Open **Constraints** in the panel inspector, or choose **Add constraints → Custom constraint…** in the context menu (**Shift+C**), to keep a measurement as the design changes. Choose **Height above floor** with a top, bottom, or center reference; **Panel dimension**; **Equal panel dimensions**; **Same level above floor**; or **Gap between panels**. Enter millimeters: 80 cm above ground is **800**, and a 20 cm opening is **200**. Height, dimension, and gap rules offer **Exactly**, **At least** (minimum), **At most** (maximum), or **Between** (both limits). For example, a gap can stay between **200** and **300** mm. Values inside the allowed interval remain free; limits do not pull panels back to a boundary. Dimension limits preserve an already-valid loose neighboring cut when spacing changes; the neighbor moves instead. Exact or equal dimensions can drive resizing, and connected spans can still adapt within their limits. Equal panel dimensions lets you choose each panel’s cut independently, including matching one panel’s width to another’s height; Same level aligns elevation. A gap measures between panel boundaries, including thickness, along X, Y, or Z. **Equal / proportional openings** keeps two such clearances related: choose each opening’s start and end panel in the selected direction, sharing a divider if appropriate. Set **Opening 2 / opening 1** to **1** for equal openings or **2** for a second opening twice as large. Both clearances stay nonnegative as you edit; use an exact gap or floor rule when a particular opening or boundary must also stay fixed.
- Use **Fixed reference position** to hold a left/right, top/bottom, back/front, or center reference at an exact world coordinate. Choose X, Y, or Z and enter **Fixed coordinate**; negative coordinates are allowed. Use **Setback between references** to preserve one panel’s reference relative to another: **Signed setback** is the second reference minus the first along the chosen axis. Zero aligns them; a negative value puts the second reference behind the first. These exact rules use rectangular panels aligned with world axes. Preview, cancel, and apply them like other constraints. Rescaling respects fixed references; copies omit absolute position rules but retain self-contained setbacks.
- Constraint changes preview before **Add constraint** or **Save constraint** applies them. For a two-panel rule, **Keep in place for this adjustment** chooses the reference panel; future edits maintain the relationship in either direction. The preview names affected panels and highlights the measurement. **Cancel** or **Escape** discards it. Connected edits preserve joints, connector sizes, and stock limits; a conflicting edit keeps the committed model and explains which rules need attention. With nothing selected, the inspector stays empty; **All constraints** opens the project’s rules explicitly, and **Done** or **Escape** closes that view. Use **Selection** or **All** to review rules, click a row to edit, clear **Enabled** to pause, or remove it. Re-enabling opens a preview. Rules and geometry changes share one Undo step and persist in autosave and project files.
- Click **All constraints** in the preview to configure **Build space**. The **Enable build space** checkbox applies immediately using saved dimensions, with Undo support. Enter exact width, height, depth and X/Z center in millimeters, then **Save build space** to apply dimension changes. The box rests on the floor and must contain your panels. Its outline highlights boundaries within 10 mm; edits beyond the space are rejected. Disable it to pause the limit while retaining dimensions. Settings support Undo, autosave and project export. Hidden and rotated panels count using rectangular stock bounds; hardware and accessories are excluded. The outline is hidden in realistic preview and exploded view.
- Floor, level, and gap rules currently support rectangular panels aligned with world axes; fixed and equal cut dimensions also support rotated/custom-outline panels. Hidden panels still participate. Gap rules measure panel boundaries, not openings, hardware, or clearance from other objects. Author new rules on ordinary panels; use **Editable values** for linked assemblies, or disassemble and disconnect their panels first. Whole-project moves and rotations respect saved rules; a floor reference stays at world Y = 0. Deleting a panel removes its dependent rules with the same undo step. Copies keep eligible internal rules but omit absolute floor requirements and relationships to panels outside the copy. Standalone assembly files do not include project-level constraints.
- Select one panel or connector to show **resize arrows** in the preview. Blocked arrows remain visible in gray; hover or focus one to see why it is blocked and highlight the implicated panels and connectors. Drag an orange arrow to pull or push along a permitted direction, making the structure wider, taller, or deeper while keeping connector angles and panel thickness fixed. Panel edge handles keep the opposite edge in place; connected panels adapt together. Hold **Shift before dragging a panel edge arrow** to resize only that panel, keeping other panels and connectors in place. Shift-drag is also available on edge arrows whose connected resize is blocked. This stops where a joint, connector, or size limit prevents further resizing; arrows perpendicular to the panel cannot resize it independently. The preview shows the change in millimeters and stops at the valid size limit. Release to apply one undoable change, or press **Escape** to cancel. Resize handles are hidden during attachment, exploded view, and linked assembly editing.
- Select several connected panels to show **Stretch connected panels** arrows where rectangular panels can extend or shorten between the selection and the fixed construction. The selection moves as one rigid section: its cuts, angles, and internal joints stay unchanged; only the identified boundary panels stretch. The rest of the build stays fixed, including when a saved rule prevents the move. Hover or focus a handle to inspect its affected panels or the reason it is blocked. Drag to preview, release for one Undo step, or press **Escape** to cancel. Arrow keys and plus/minus also work on a focused handle; Shift uses ten times the step. Movement stops at joint, stock-size, saved-rule, build-space, panel-overlap, or hardware-clearance limits. Directions follow the panels after rotation. Loose or fully selected constructions have no boundary to stretch; linked assemblies, custom-outline selections, and ambiguous or unsupported boundaries remain unavailable. These checks use the editor’s existing rectangular stock and CAD hardware bounds.
- Hold **Control before pulling a panel resize arrow** to repeat its rectangular compartment in that direction. Pull a top panel upward to stack another bay, an outside side panel outward to add a bay beside it, or a front/back edge arrow to grow in depth. The source compartment highlights and the preview snaps to complete bays, showing the repeat count and how many existing panels are reused. Pull back to remove previewed additions; the original construction stays in place. Release applies everything in one Undo step and selects the corresponding panel in the last traversed bay so you can keep extending; **Escape** cancels. With a panel arrow focused, **Control + ArrowUp / ArrowRight / +** adds one bay. Sideways and stacked bays share a boundary panel; depth repeats add a fitted divider between separate four-panel frame sections. If a needed wall, ceiling, or divider already matches the required dimensions, thickness, and placement, it is reused with its existing finish; only missing panels and required joint changes are added. Partly overlapping or differently sized panels still block the repeat. You can pull through complete existing bays to extend farther; releasing over an unchanged bay only advances selection and creates no Undo step. Connector gaps remain part of each bay. New connectors slide along their joints to clear nearby hardware; retained existing connectors stay in place. If there is not enough room, the preview stops before adding that bay. Clearance uses conservative bounds around the CAD parts and still needs checking before fabrication. Repetition uses an empty four-sided compartment with matching 18–19 mm ordinary panels, including rotated frames. For depth repeats, an exactly matching closing panel on the outgoing face can serve as the divider, and you can continue from the newest depth bay with its trailing divider. Other closing faces, internal contents, linked assemblies, custom outlines, and TROFAST panels are excluded. Choose an outside panel when a shared panel borders more than one possible source compartment. Inward normal arrows are unavailable. Existing obstacles, joint fit, saved rules, and project limits can stop growth. Control-drag on the board itself remains **Move & snap**.
- Select a vertical rectangular panel and use **Extend to ground** under **Dimensions** or in its context menu. The lower edge extends exactly to ground level (Y = 0); the upper edge, other panels, and existing connectors stay fixed. Rotated panels can extend along either width or height. The action explains when a joint, collision, assembly constraint, or size limit prevents the extension, and supports undo, redo, and autosave.
- Click a panel in **Studio** and use **arrow keys** to move it **1 cm**, or **Shift + arrow keys** for **10 cm**. Movement follows the current view and the panel’s rotated axes, including after orbiting behind or above the assembly. Connected panels resize while connector angles, thicknesses, and hardware sizes stay fixed. A move that cannot preserve the joints or panel limits leaves the project unchanged and explains why. Free panels and fully selected assemblies translate together. Holding a key forms one undo step. While editing Objects, amber surface highlights and focusable warning icons identify narrow sections of the evaluated solid. Hover or focus an icon for details. The early check flags continuous solid spans below 91 mm (40 mm minimum panel cut, 16 mm stock, and two measured 17.5 mm connector seats), including Boolean remnants; operand subdivisions alone do not trigger it. It is advisory: fitted-face exceptions may work, and wider sections can still fail hardware clearance. Convert to panels performs the full check for the chosen thickness. Warnings update with drafts and gestures, remain outside saved projects, and disappear outside Objects mode.

**Auto-add connectors** restores removed pieces on selected joints at their saved positions when they still fit. Select the adjoining panels (or the whole construction) and run the command again; finishes and individual slide adjustments are retained. Pieces blocked by other hardware or inserts stay removed. Restoration supports Undo/Redo and saved projects.

**Auto-add connectors** also fills exposed corner ends beside existing T/cross joints when two panels extend beyond the other members. Select the two deeper panels (or select the whole construction), then choose **Build tools → Auto-add connectors**. Existing shared joints and hardware stay in place; added 90° pieces use the free ends, and running the command again does not duplicate them. There must be room for the entire clamp beyond the shorter stock and clear of other hardware. Disassemble linked assemblies before adding these supplemental corners.

To keep two neighboring compartments equal, select their three parallel boundary panels—in any order—then open **Constraints → Add constraint**. The editor prepares **Equal / proportional openings**, chooses X/Y/Z from the panel orientation, and places the shared divider in both opening pairs. Keep the ratio at **1** and click **Add constraint** to save it; Cancel leaves the project unchanged. For a 2×2 grid, repeat for each row’s left/divider/right boundaries and each column’s bottom/middle/top shelves. To also match across rows or columns, choose Equal / proportional openings and select the two pairs of boundaries to compare. These are ongoing relationships, unlike the one-time **Distribute evenly** command.

When resizing a connected construction, manually positioned connectors now spread or contract proportionally along their shared joint, retaining their order and custom spacing. If shrinking would crowd installed pieces together, use a larger size or adjust/remove hardware first. Removed pieces no longer count toward the minimum shared-edge length, including T/cross joints. Auto-add connectors restores only removed pieces whose saved positions still fit after shrinking; expand the joint to make room for the rest. Local panel-only resizing continues to keep hardware fixed. Connector positions remain part of the same resize undo step and persist in saved projects.

Select two connectors joining the same panels with matching type, material, and color, then choose **Add connectors between** in the inspector or preview context menu. Enter a quantity and click **Add connectors** to space new matching pieces evenly between them. Existing pieces and panels stay fixed. Quantities that overlap hardware are rejected; each connection supports up to 20 stored pieces. Disassemble managed assemblies first. Cancel/Escape makes no changes; additions support Undo/Redo, autosave, and project export.

Select overlapping connectors and choose **Separate overlapping connectors** in the preview context menu (right-click, or focus the canvas and press Shift+F10). The command slides selected overlapping pieces along their existing joints, keeping panels and unselected hardware fixed. If no fit is found for the full selection, nothing changes; select neighboring hardware too or make more space. Repairs support Undo/Redo, autosave, and project export. Auto-add connectors now checks CAD-part envelopes and slides new pieces to avoid surrounding hardware, using one connector when two cannot fit. These conservative bounds do not guarantee fabrication clearance.

## Geometry and source references

Manufacturer references:

- [Connector range and current thickness limits](https://www.playwood.it/en/diy-wooden-projects-connectors/)
- [Official metric technical drawings](https://www.playwood.it/site/assets/files/18237/technical_information_playwood_connectors.pdf)
- [Manuals and project inspiration](https://www.playwood.it/en/business-page-landing-post-login/manuals-catalogs/)

Angled connectors accept 16–19 mm panels. T/cross use the current product page's 18–19 mm range; the older technical PDF lists 17–19 mm. The supplied connector models have a 40 mm depth along the joint.

**90° connectors** offer **Plastic** and **Metal** under **Connector material**, both when attaching panels and when editing selected hardware. Metal uses a silver cast finish with procedural grain, surface relief, and soft room reflections. Other connector angles use plastic; changing metal hardware to another type restores plastic. The previous plastic color is retained. Material choices support multiselect, undo/redo, autosave, project export/import, connector filtering, and separate material quantities in the parts dialog and CSV. The metal finish uses the existing 90° CAD profile; it is a visual material variant, not a separate measured metal model.

Connector meshes use the supplied CAD export in `resources/connectors-3d/Connettori sharing.obj`, including the distinct 90°, 105°, 150°, T, and cross profiles and their separate clamp parts. The original OBJ, 3DS, and STEP files are retained in `connectors-3d`; the OBJ is bundled locally, with no external model requests. The geometry is shared across connector instances and used in the studio, attachment previews, and room preview. Panel spacing follows the shoulders in each connector profile, including the continuation branches of T/cross joints. The supplied models depict nominal 18 mm slots and do not include separate screw geometry. Manufacturing tolerances, tightening, material strength, load capacity, and cut-through interference with connectors are not simulated. Front/back attachment previews may require an accessible edge. Starter assemblies are editable design studies, not certified construction plans. Check physical clearances against the official drawings before fabrication.

The app stores panels in local XY coordinates, with thickness on local Z. Project values are millimeters and Euler radians; the renderer converts to meters. Connections form a directed attachment tree, with optional non-driving supports for additional hardware between already positioned panels.
